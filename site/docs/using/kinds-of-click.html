Using Jumpr

Kinds of click

Hold a key on the last letter of a label to right-click, double-click and more.

Hold a key on the last letter

Type the label as usual, and hold a key while you type its last letter.

Hold on the last letterClick
⇧Right-click
⌘⌘-click, which opens a link in a new tab
⌥Double-click
⌃⇧-click, which selects from the selected row to this one

With nothing held, Jumpr clicks.

Tip

Only the last letter counts. Holding ⇧ on an earlier letter only narrows the labels.

Change the keys

Those are the keys Jumpr starts with. On the panel's Shortcuts tab you can give each kind of click another key, or None. Choosing a key another click already has swaps the two. See The panel.

A click set to None can't be reached from a label. If its key was ⌘, ⌥ or ⌃, that key goes back to working as a shortcut. If it was ⇧, ⇧ on the last letter gives a plain click.

In persistent mode

A right-click ends persistent mode, because the menu it opens gets no labels. Use the arrow keys in that menu.
