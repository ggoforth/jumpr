## Turn on scroll mode

Press [[⌘]] [[⇧]] [[J]]. Every scrollable area on every display gets a letter. The area you scrolled last in that window, or the one holding the keyboard focus, is already outlined.

Your pointer never moves. While scroll mode is on, the menu bar icon is shown filled.

## Keys in scroll mode

| Key | What it does |
|---|---|
| [[J]] / [[K]] | Scrolls the outlined area down / up a line |
| [[D]] / [[U]] | Half the area's height down / up |
| [[G]] / [[⇧]] [[G]] | To the top / the bottom |
| An area's letter | Outlines that area instead |
| [[F]] | Brings the letters back |
| [[Esc]], or [[⌘]] [[⇧]] [[J]] again | Leaves scroll mode |

Holding a key keeps scrolling. Any scroll hides the letters; press [[F]] to see them again.

Jumpr takes the keys while scroll mode is on. Shortcuts with [[⌘]], [[⌃]] or [[⌥]] still work.

## Leaving scroll mode

Besides [[Esc]], scroll mode ends when you click anywhere, switch apps, lock the screen or pause Jumpr. Pressing the label hotkey leaves scroll mode and shows labels.

You can change the scroll shortcut on the panel's **Shortcuts** tab. See [The panel](the-panel.md).

> ⚠️ **Some areas have nothing to scroll.** Every area gets a letter, including ones that can't scroll. Picking one does nothing. See [Known limits](../help/known-limits.md#scroll-mode).
