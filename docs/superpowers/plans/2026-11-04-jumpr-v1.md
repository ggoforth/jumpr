# Jumpr v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu bar app that labels every visible clickable element on every display on a hotkey, and presses the one whose label you type — with a background cache so labels appear in under 20 ms.

**Architecture:** A pure-logic library (`JumprCore`: geometry, tree walk, labels, cache state machine, power policy) tested with `swift test`, and a thin app target (`Jumpr`: Accessibility API, window server, key listener, overlay, settings) that wires it to the live system. The app is built to spike parity first (cold scan on every trigger), then the cache and watcher are added on top.

**Tech Stack:** Swift 6.4 toolchain in Swift 5 language mode, AppKit, SwiftUI (Settings only), ApplicationServices (AX), CoreGraphics (window list, event tap), IOKit.ps (power source), ServiceManagement (login item), Swift Testing. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-04-jumpr-design.md` — read it first. Working reference code: branch `spike/cold-scan`, file `spike/Spike.swift` (throwaway; lift what helps).

## Global Constraints

- macOS 15 or later. `platforms: [.macOS(.v15)]`.
- Swift package, not an Xcode project. Both targets and the test target use `.swiftLanguageMode(.v5)`.
- No third-party dependencies.
- AppKit everywhere; SwiftUI only inside the Settings window.
- Bundle ID `com.greggoforth.jumpr`. Executable name `Jumpr`. `LSUIElement` true (no Dock icon).
- Sign every build with the identity `Apple Development` (stable identity keeps the Accessibility grant across rebuilds; ad-hoc signing resets it).
- Default hotkey `⌘⇧Space` (key code 49).
- Label defaults: size 15 pt (range 10–32), label color `FFD60A`, text color `000000`.
- Log file `~/Library/Logs/Jumpr.log`.
- All coordinates passed between components are **global, top-left origin** (the space the Accessibility API and `CGWindowListCopyWindowInfo` use). Only `Overlay` converts to AppKit's bottom-left.
- The key listener's handler must never block: no AX calls, no scans, no waits on it.
- All Accessibility calls run off the main thread. Never two scans of the same app at once: one serial queue per process ID.
- No repeating timers anywhere. One-shot delays only (settle, spacing).
- Per-app scan budget 500 ms; per-request AX timeout 250 ms.
- The spike (`jumpr-spike`) uses the same hotkey. Run `pkill -x jumpr-spike` before launching Jumpr.
- Build on branch `build/v1` in its own worktree, cut from `main` after this plan is merged there. There is no remote yet.
- Commit after every task with `git add -A && git commit -m "<message>"`. Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Never tag anything.
- Steps that say "ask Greg" need his hands or eyes (a real key press, a look at the screen). Batch them: finish everything else in the task first, then ask once.

## Review Focus

Conditions the spec implies but does not spell out, most likely first. Each has a test or check in the task that owns the code.

1. **The target dies between paint and press** (app quits, window closes, page navigates). Expected: no press, no crash, labels clear. → Task 7 (`pressDecision` with `nil`), Task 11 (`appGone`), Task 7 manual step.
2. **An app is hung.** Expected: every other app's labels still appear; total wait bounded by the 500 ms budget; the watcher does not pile scans onto it. → Task 3 (deadline test), Task 5 (`kill -STOP` check), Task 11 (failed-scan spacing test).
3. **Trigger pressed again while scans are in flight** (double tap, or Esc then trigger). Expected: one clean session, late results from the cancelled one discarded. → Task 6 (generation check + double-signal check).
4. **Displays change while labels are up** (unplug, resolution change, clamshell). Expected: session cancels, overlays rebuild, next trigger correct. → Task 4 (`screenIndex` test), Task 6 (cancel on screen change).
5. **Accessibility permission revoked while running.** Expected: typing is never blocked; onboarding reappears. → Task 9 (trust-change notification + manual step).

### Task 3: Tree walk

**Files:**
- Create: `Sources/JumprCore/TreeWalk.swift`
- Test: `Tests/JumprCoreTests/TreeWalkTests.swift`

**Interfaces:**
- Consumes: `WindowStack`, `WindowID` (Task 2)
- Produces:
  - `struct ElementID: Hashable { let raw: AnyHashable; init(_ raw: AnyHashable) }`
  - `struct NodeInfo { var role: String; var frame: CGRect?; var enabled: Bool?; var children: [any AXNode] }`
  - `protocol AXNode { var id: ElementID { get }; func info() -> NodeInfo?; func isSelected() -> Bool; func visibleRows() -> [any AXNode]? }`
  - `struct Target: Equatable { let id: ElementID; let rect: CGRect; let role: String; let pid: Int32; let window: WindowID? }`
  - `enum Roles { static let text: Set<String>; static let leaf: Set<String>; static let clickable: Set<String> }`
    - `text` = `AXTextField, AXTextArea, AXComboBox`
    - `leaf` = `text` + `AXButton, AXLink, AXCheckBox, AXRadioButton, AXPopUpButton, AXMenuButton, AXDisclosureTriangle, AXSlider, AXIncrementor, AXColorWell, AXDockItem`
    - `clickable` = `leaf` + `AXMenuItem, AXMenuBarItem, AXRow`
  - `enum WalkScope { case window(id: WindowID, bounds: CGRect, appWindows: Set<WindowID>); case system(screens: [CGRect]) }`
  - `struct WalkResult { var targets: [Target]; var nodes: Int; var timedOut: Bool }`
  - `func walk(root: any AXNode, pid: Int32, scope: WalkScope, stack: WindowStack, deadline: Double, now: () -> Double) -> WalkResult`

**Algorithm** (per node, depth-first, `clip` starts as the window bounds for `.window`, `CGRect.infinite` for `.system`):

1. Stop if depth ≥ 80 or already timed out. If `now() > deadline`: set `timedOut`, stop.
2. Count the node. Call `info()` once; `nil` → return.
3. Role `AXColumn` → return.
4. If frame is non-nil with width > 0 and height > 0: `r = frame ∩ clip`; if `r` is empty → return (prunes the subtree); if role is `AXScrollArea`, `clip = r` for descendants.
5. If role ∈ `Roles.clickable`, `enabled != false`, and `r` exists with width ≥ 4 and height ≥ 4: let `c` = center of `r`. `.window` scope → keep if `stack.isVisible(c, window:pid:appWindows:)`. `.system` scope → keep if any screen contains `c`. Kept targets carry `rect = r` and `window` = the scope's window id (`nil` for system).
6. Role ∈ `Roles.leaf` → return.
7. Role `AXMenuBarItem` or `AXMenuItem` → return unless `isSelected()`.
8. Children = `info.children`; for role `AXTable` or `AXOutline`, use `visibleRows()` instead when it is non-nil and non-empty.
9. Recurse.

  - `enum Labels { static let alphabet: [Character]` (`"ASDFGHJKLQWERTYUIOPZXCVBNM"`) `; static func length(forEstimate n: Int) -> Int; static func frame(length: Int, target: CGRect, screen: CGRect, fontSize: CGFloat, advance: CGFloat) -> CGRect; static func screenIndex(for p: CGPoint, screens: [CGRect]) -> Int? }`
  - `struct LabelPool { init(length: Int); let length: Int; mutating func next() -> String?; var remaining: Int }` — hands out labels in order, never repeats, `nil` when exhausted
  - `struct LabelSession { init(); private(set) var typed: String; var labels: Set<String>; mutating func handle(_ key: Key) -> Outcome }`
    - `enum Key: Equatable { case character(Character), backspace, escape, hotkey, modified, other }`
    - `enum Outcome: Equatable { case passThrough, swallow, narrowed(String), cancelled, matched(String) }`

**Rules**
- `length(forEstimate:)`: headroom ×1.5 — `ceil(1.5·n) ≤ 26` → 1; `≤ 676` → 2; else 3.
- `LabelPool` order: index `i` → digits of `i` in base 26 over `alphabet`, most significant first, padded to `length` (so length 2 gives `AA, AS, AD, …`).
- `frame`: `w = ceil(length·advance + fontSize·0.6)`, `h = ceil(fontSize·1.3)`. `x = target.width < 60 ? target.midX − w/2 : target.minX + 2`. `y = target.midY − h/2`. Then clamp the rect inside `screen`. Result is in global top-left coordinates.
- `LabelSession.handle`: `.modified` → `.passThrough`. `.escape` / `.hotkey` → `.cancelled`. `.backspace` → drop last typed letter → `.narrowed(typed)` (`.swallow` if nothing typed). `.character(c)` (uppercased) → if `typed + c` equals a label → `.matched`; else if any label starts with `typed + c` → append, `.narrowed`; else `.swallow`. `.other` → `.swallow`.

**Trigger flow in this task (cold path only — no cache yet):**
1. If active → `cancel()` and return. Otherwise bump `generation`, set active, `tap.capturing = capture`.
2. `stack = WindowServer.snapshot()`; list pids in stack order; for each regular app with a visible window call `registry.enableIfNeeded`.
3. Create `LabelPool(length: Labels.length(forEstimate: lastTotal ?? 200))`, where `lastTotal` is the previous trigger's label count.
4. For each pid: one `ScanRequest` per window from `scanner.appWindows(pid:)` plus one system request. Dispatch all.
5. As each `WindowScan` completes on main: if its generation is stale or the session is inactive, drop it (Review Focus 3). Otherwise, for each target: pick the overlay with `Labels.screenIndex`; take `pool.next()` (none left → count it as overflow, skip); compute `Labels.frame`; `overlay.add`; record `label → (target, drawnRect, layer, overlayIndex)`; insert into `session.labels`.
6. Key handling: `.narrowed(prefix)` → hide layers whose label lacks the prefix; `.cancelled` → `cancel()`; `.matched(label)` → look up, `cancel()`, call `onMatched`.
7. `cancel()`: bump generation, inactive, `tap.capturing = false`, clear overlays, reset session.
8. Cancel and rebuild overlays on `NSApplication.didChangeScreenParametersNotification` (Review Focus 4); cancel on `NSWorkspace.activeSpaceDidChangeNotification`.
9. `SIGUSR1` now calls `trigger(capture: false)` and cancels itself after 2 s.

**Files:**
- Create: `Sources/JumprCore/CacheStore.swift`
- Test: `Tests/JumprCoreTests/CacheStoreTests.swift`

**Interfaces:**
- Consumes: `Target`, `WindowID` (Tasks 2–3)
- Produces:
  - `struct CacheConfig { var settle = 0.3; var minSpacing = 1.0; var spacingFactor = 20.0; var restlessWindow = 1.0; var restlessStrikes = 3; var restlessQuiet = 2.0; var afterPress = 0.1; init() }`
  - `enum Served: Equatable { case clean([Target]), stale, never }`
  - `struct Due: Equatable { let window: WindowID; let pid: Int32 }`
  - `final class CacheStore { init(config: CacheConfig = .init())`
    - `func changed(window: WindowID, pid: Int32, at t: Double)`
    - `func pressed(window: WindowID, pid: Int32, at t: Double)`
    - `func scanStarted(window: WindowID, pid: Int32, at t: Double)`
    - `func scanFinished(window: WindowID, pid: Int32, targets: [Target], startedAt: Double, at t: Double, background: Bool, failed: Bool)`
    - `func windowGone(_ w: WindowID)` / `func appGone(pid: Int32)`
    - `func served(_ w: WindowID) -> Served`
    - `func count(_ w: WindowID) -> Int?` — last known label count, for the length estimate
    - `func isRestless(_ w: WindowID) -> Bool`
    - `func due(at t: Double, warm: (Due) -> Bool) -> [Due]` — windows whose background re-scan should start now, priority ones first
    - `func nextWake(after t: Double, warm: (Due) -> Bool) -> Double?` — earliest future time `due` could return something; `nil` if nothing is pending
    - `}` — not thread-safe; main thread only

**Rules** (design §7.4):
- `changed`: only on the clean → stale transition: if `t − lastScanFinished < restlessWindow`, strikes += 1, else strikes = 0. Mark stale; `lastChange = t`. Strikes ≥ `restlessStrikes` → restless. A window never scanned is created as stale with no targets (`served` → `.never` until a scan lands).
- `pressed`: mark stale, `priority = true`, `pressedAt = t`, forget changes before `t`.
- A window is **due** when all hold: stale; `warm` says yes; no scan of its pid in progress; and
  - priority: `t ≥ lastChangeSincePress + settle`, or no change since the press and `t ≥ pressedAt + afterPress`. Spacing does not apply.
  - restless: `t ≥ lastChange + restlessQuiet` **and** `t ≥ appNextAllowed[pid]`. *(Corrected during the build: as first written this skipped the per-app spacing, which would have let a restless window exceed the ~5% cap. Design §7.4 exempts only Jumpr's own press.)*
  - otherwise: `t ≥ lastChange + settle` **and** `t ≥ appNextAllowed[pid]`.
- `scanStarted`: pid is scanning. *(Corrected during the build: scanning is a per-pid counter, not a flag, because a hotkey scan and a background scan of one app can overlap.)*
- A press that lands while a scan of that window is running (`pressedAt > startedAt`) is kept: `scanFinished` stores the targets but leaves the window stale with its priority. *(Added during the build: as first written the press was lost and old labels were served as clean.)*
- `scanFinished`: pid no longer scanning. If `failed` → targets untouched, still stale. Else store targets; clean unless `lastChange > startedAt` (changed mid-scan → still stale). Clear priority. If the window was restless and the scan ended clean: restless off, strikes = 0 (strikes are otherwise only reset in `changed`). If `background`: `appNextAllowed[pid] = t + max(minSpacing, spacingFactor × (t − startedAt))` — also when `failed`, so a hung app is not hammered.
- `windowGone` / `appGone`: drop the entries (and the pid's scanning flag and spacing).

### Task 13: Watcher and the cached trigger

**Files:**
- Create: `Sources/Jumpr/Watcher.swift`

**Interfaces:**
- Consumes: `CacheStore`, `Served`, `Due` (Task 11); `fixUp`, `Shown` (Task 12); `Scanner` (Task 5); `Controller` internals (Task 6)
- Produces:
  - `final class Watcher { init(cache: CacheStore, scanner: Scanner, registry: TreeRegistry); var warm: (Due) -> Bool` (set by Task 14; default `{ _ in true }`) `; func start(); func stop(); func notePress(window: WindowID, pid: Int32); func pump() }`
    - One `AXObserver` per app that has an on-screen window, on a dedicated background run-loop thread. Notifications: `AXWindowCreated, AXWindowMoved, AXWindowResized, AXWindowMiniaturized, AXWindowDeminiaturized, AXFocusedWindowChanged, AXFocusedUIElementChanged, AXLayoutChanged, AXUIElementDestroyed, AXSelectedChildrenChanged, AXMenuOpened, AXMenuClosed, AXLoadComplete, AXTitleChanged`. Resolve each to its window (`AXWindow` attribute of the element, then `_AXUIElementGetWindow`); unresolvable → mark every on-screen window of that app. Hop to main, call `cache.changed`, then `pump()`.
    - Workspace notifications: launch → observe; terminate → `cache.appGone`, drop observer; activate / hide / unhide / `activeSpaceDidChange` / `didChangeScreenParameters` / `didWake` → mark all of the affected apps' on-screen windows changed.
    - `pump()`: for each `cache.due(at: now, warm:)` whose window is on screen and `anyVisible` → `cache.scanStarted`, `scanner.scan(background: true)`, and on completion `cache.scanFinished(..., failed: timedOut && targets.isEmpty)` then `pump()` again. Then schedule **one** one-shot `DispatchWorkItem` at `cache.nextWake` (cancel the previous one). No repeating timer.
    - `stop()`: remove all observers, cancel the work item.
- Changes to `Controller.trigger` (design §7.1):
  1. Label length estimate = sum of `cache.count(w) ?? 100` over visible windows, plus last system count.
  2. Per visible window, by `cache.served`:
     - `.clean(targets)` → paint now; then issue a foreground scan and, when it lands, apply `fixUp(shown:fresh:)` for that window (remove layers, move layers, add from the pool) and call `cache.scanFinished(background: false)`.
     - `.stale` → paint nothing; issue a foreground scan (if `scanner.isScanning(pid:)`, the per-pid queue makes it wait its turn); paint when it lands.
     - `.never` → same as stale.
  3. System pieces (menu bar, extras, Dock) are never cached: scanned on every trigger as in Task 6.
  4. `Readout` records for each window which of the three it was.
- After a press that returned `.pressed` or `.clicked` on a target with a window: `watcher.notePress(window:pid:)` → `cache.pressed` + `pump()`.
